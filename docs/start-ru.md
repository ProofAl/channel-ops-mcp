# Channel Ops для YouTube

Channel Ops помогает ответить на вопрос после выпуска ролика: сколько денег он принёс после возвратов, исполнения заказов, монтажа, продвижения и времени команды.

**Попробовать без установки.** Откройте [демо](https://channel-ops-lab.knowingfoxglove4.chatgpt.site/?lang=ru) или добавьте адрес ниже в ChatGPT либо Claude как пользовательский MCP-сервер без авторизации. В публичном демо можно посчитать вклад кампании на вымышленных цифрах и собрать UTM-ссылку.

```text
https://channel-ops-lab.knowingfoxglove4.chatgpt.site/demo/mcp
```

**Первый запрос.** «За выпуск получили 200 долларов. Исполнение заказов и комиссии стоили 50, производство и продвижение с учётом времени команды — 125. Сколько осталось? Что изменится, если монтаж занял ещё час за 30 долларов?»

**Свой канал.** Локальная версия читает статистику YouTube, показывает недавние ролики, готовит изменения заголовков и сохраняет рабочий журнал. Установите Python-пакет из репозитория в отдельное окружение. Подключите конкретный канал через Google OAuth. Для применения нового заголовка владелец сверяет ролик в терминале. [Установка для GPT и Claude](clients.md) · [Подключение канала](youtube.md)

**Проверка спроса.** Для одного ролика или размещения в СМИ задайте предложение, источник, идентификатор кампании и окно наблюдения. Фиксируйте уникальные квалифицированные команды, построенные ими отчёты, повторное использование и только фактически полученные оплаты. Шаблон обращения заполняется публично. Для разбора достаточно описать задачу без клиентских данных. [Заявка на пилот](https://github.com/ProofAl/channel-ops-mcp/issues/new?template=pilot.yml)
